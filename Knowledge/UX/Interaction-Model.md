# Interaction Model

Status: Current
Confidence: High
Source: PRODUCT_BLUEPRINT.md, src/components/MockHome.tsx

## Canonical summary
The interaction model is designed to feel continuous, social, and action-oriented. Users move from content to connection to transaction without leaving the core context.

## Interaction patterns
- Tap-to-open profile and chat from feed content.
- Contextual action bubbles in chat.
- Booking flows triggered from conversation rather than from a separate storefront.
- Overlay and modal-driven states for rich task completion.

## Implementation evidence
- The home component wires together feed cards, profile views, chat windows, booking, and payment flows in a single orchestrated surface.
